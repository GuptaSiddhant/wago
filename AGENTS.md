# AGENTS.md

## Frontend tooling: use NUB, not npm

This repo uses **NUB** (the all-in-one Node.js toolkit, `nub` on PATH) instead of npm.
Do not run `npm`, `npx`, `yarn`, or `pnpm` — they are not installed here.

- Install deps: `nub install` / `nub ci`
- Add a dependency: `nub add <pkg>`
- Run a package script: `nub run <script>` (from `frontend/`)

Frontend scripts (`frontend/package.json`):
- `nub run dev` — Vite dev server
- `nub run build` — `tsc -b && vite build`
- `nub run lint` — `oxlint`

## Backend

- Build/vet: `go build ./...`, `go vet ./...`
- Tests: `go test ./...`
- The `frontend/src/routeTree.gen.ts` is generated by the TanStack Router Vite
  plugin at dev/build time; keep it in sync with new files under `frontend/src/routes/`.
